# 時系列状況把握翻訳プロトタイプ (Context-Aware Translator)

連続する映像フレーム（カメラ画像）と音声文字起こしから、その場の状況や文脈をAI（Gemini）が読み取り、最適な翻訳を3パターンで出力するWebアプリケーションです。

## 主な特徴
- **0.5秒サイクルの高速サンプリング**: カメラ映像をミリ秒単位で滑らかにストック（最大10枚）。
- **進捗一体型UI**: 画面上のステータスバッジ自体がキャプチャタイミングを示すプログレスバーとして機能。
- **3バリエーションの翻訳**:
  1. **【直訳】**: 映像を無視した言葉通りの日本語訳。
  2. **【意訳（シンプル）】**: 余計な説明を省き、文脈（対象物など）を自然に補完したセリフ。
  3. **【説明・回答付き意訳】**: ト書きや、画像の内容に対する具体的な回答まで含んだ詳細な訳。

## ファイル構成
- `index.js` - Expressを使用したバックエンドサーバー
- `public/index.html` - カメラ制御・プログレスバー・出力を行うフロントエンド画面
- `system_instruction.md` - AIの役割と出力形式（JSON）を定義するプロンプト
- `user_prompt.md` - AIへの解析条件やデータ連携を定義するプロンプト
- `.env` - `GEMINI_API_KEY` などの環境変数管理

## 起動方法
1. **環境変数の設定**
   `.env` ファイルを作成し、APIキーを記述。
   ```env
   GEMINI_API_KEY=あなたのAPIキー
   ```
2. **サーバーの起動**
   ```bash
   Docker compose up -d
   ```
3. **ブラウザでアクセス**
   `http://localhost:3000` を開き、カメラを許可して「翻訳開始」をクリック。`;
